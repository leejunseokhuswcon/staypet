# StayPet Product Context

## 제품 한 줄 정의
떠난 반려동물의 모습과 습관을 AI로 재현해, 함께 살던 집에서 스스로 생활하게 하고 사용자가 다시 일상을 함께할 수 있게 하는 디지털 반려동물 시뮬레이션.

장르: **AI 기반 디지털 반려동물 라이프 시뮬레이션**
핵심 차별점: **“다시 만나는 경험”보다 “다시 함께 사는 경험.”**
브랜드 방향: **“다시, 함께 지내는 일상.”**

## 정서적 포지셔닝
StayPet은 실제 반려동물을 “부활시켰다”고 주장하지 않는다. 캐릭터가 `나 돌아왔어`, `난 죽지 않았어`처럼 실제 본인인 것처럼 말하지 않는다. 추모 서비스보다 따뜻하고 편안한 생활감을 지향한다.

## MVP
지원: 강아지, 고양이. 후속: 조류, AR, 3D, 고급 실사형. MVP 기본은 반실사형 2.5D.

## 핵심 생활 루프
자율 NPC가 걷기/이동, 쉬기/잠자기, 먹기, 배변, 놀기, 사용자에게 다가오기를 한다. 강아지/고양이별 대표 행동 2~3개를 추가한다.

## 오프라인 생활
24시간 서버 애니메이션이 아니라 마지막 접속 시각과 생활 파라미터로 경과시간을 계산한다. 재접속 시 수면/식사/이동/배변 이벤트와 현재 위치/행동/흔적을 결정한다. 활동 보고서 팝업은 띄우지 않는다.

## 의무 X, 교감 O
미접속 패널티, 굶주림에 따른 질병/죽음, 죄책감 알림 금지. 생활 흔적은 남지만 해로운 페널티는 없다.
연속 방문이 끊기는 것 자체는 벌이 아니다 — 다음 방문에 조용히 1일차부터 다시 시작할 뿐,
상실 문구도 경고도 회수도 없다(아래 `## 출석 보상` 참조).

## 상태 표현
숫자형 Hunger/Happiness/Cleanliness 게이지 금지. 행동과 짧은 말풍선(`배고파요`, `졸려요…`, `놀아줘요`, `배변했어요`)으로 표현한다.

## 개인화
외형: 사진 최소 1장, 추가 사진 선택, 동영상 선택(외형 보조용).
행동: 이름, 성별, 쓰다듬기 선호 부위, 활동량, 식사 주기, 짖음/울음 정도, 배변 주기, 수면양.
장기적으로 장소×행동×시간×물건×사람의 Memory Profile/Graph를 고려한다.

## 캐릭터 생성
후보 2~3개 → 선택 → 귀/털/체형/눈/색/무늬 간단 보정. RPG 꾸미기가 아니라 우리 아이와 더 닮게 만드는 목적.

## Home Mode
사용자 실제 공간 사진 1장, 공간 분류 없음, 이동영역은 사용자가 직접 표시. 카메라는 기본 고정이며 캐릭터 터치 시 부드럽게 확대/이동 후 복귀.

## 직접 상호작용
밥그릇, 장난감, 배변 오브젝트를 직접 터치. 캐릭터 터치 후 쓰다듬기 가능. 선호 부위 일치 시 하트 + 긍정 반응.

## 꾸미기
실제 집 사진의 정체성을 유지하면서 밥그릇, 침대/쿠션, 장난감, 스크래처, 러그, 화분, 조명, 액자, 작은 가구 등을 배치한다. 일부 오브젝트는 실제 행동과 연결된다.

## 첫 만남
5~10초. 시스템 문구 `{이름}가 우리 집으로 찾아왔어요.` 과도한 감정 연출 금지, 홈으로 자연스럽게 이어짐.

## 앨범 / 추억 사진
기존 사진/영상 앨범. 현재 홈 장면을 UI 없이 저장하고 `저장 완료` 표시. MVP 전용 SNS 공유 없음.

## 알림
옵트인, 낮은 빈도. `보리가 지금 쿠션에서 쉬고 있어요.` 같은 생활 소식은 허용. 접속 압박/외로움/방치 죄책감 금지.

## 출석 보상
**이번 달 연속 방문 일수**에 따라 그날 첫 방문에 하트를 준다. (구현·확정 완료)

- 같은 달 안에서 연속으로 방문하면 일수가 쌓이고, 보상 구간이 올라간다.
- 연속이 끊기면 **다음 방문에 조용히 1일차부터 다시 시작한다.**
- **새 달이 시작되면 연속 방문 일수가 초기화된다.**
- 하트 잔액, 구매한 아이템, 놓아둔 오브젝트, 해금은 **어느 경우에도 초기화되지 않는다.**
- 상실·압박 문구를 쓰지 않는다: `연속이 끊겼어요`, 카운트다운, `내일 또 오세요`, 불꽃 아이콘 금지.
  UI 는 현재 연속 일수와 오늘 보상만 담담하게 말한다.

이전 판의 `함께한 날 = 누적 방문일, 하루 빠져도 초기화 없음` 규칙은 위 규칙으로 대체됐다.
누적 방문일 기반 오브젝트 해금은 현재 구현되어 있지 않으며, 다룰 경우 별도로 정한다.

## 비즈니스 모델
기본 생활 경험/기본 생활 오브젝트 무료. 무료 재화 + 프리미엄 재화. 유료는 특별 가구/장난감/새로운 행동 장면을 만드는 오브젝트. 결제해야 펫이 행복해지는 구조 금지.

## KPI
Primary: 사용자가 며칠 뒤에도 다시 아이를 보러 돌아오는가. 보조: 생성 완료율, 상호작용 발생률, 유사도 만족도, 구매 전환. 구체 수치는 베타 후 확정.
