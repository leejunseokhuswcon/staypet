# StayPet Design Rules

상태: **Low-fi 단계용 임시 디자인 원칙**. 최종 High-fi 디자인 시스템은 미확정.

## 핵심
- 추모 앱처럼 어둡고 무겁지 않게.
- 일반 모바일 게임처럼 HUD 복잡하게 하지 않기.
- 실제 공간과 캐릭터가 주인공.
- 사용자가 “앱 조작”보다 “아이를 바라보고 만진다”고 느끼게.

## 홈
우선순위: 실제 공간 사진 → 캐릭터 → 생활 오브젝트 → 최소 UI.
금지: Dashboard 카드, 숫자 상태 패널, 항상 떠 있는 버튼 다수, 큰 메뉴, RPG HUD.

## 로그인
풀숲에서 뛰어노는 강아지 배경 + StayPet 로고 + 세로로 쌓인 가로형 버튼 3개. 별도 소개 슬라이드 없음.

## 문답
한 화면 한 질문 중심. 빈도형은 왼쪽 적음→오른쪽 많음/자주, 5단계. 설문지처럼 빽빽하지 않게.

## 카피
짧고 직접적으로: `업로드 완료`, `저장 완료`, `{이름}가 우리 집으로 찾아왔어요.`
피하기: `사진 1장만으로도 시작할 수 있어요`, 긴 기능 설명, AI 기술 자랑, 부활 암시, 실제 펫 본인처럼 말하는 카피.

## 상태 UI
숫자형 meter 금지. 행동 + 짧은 말풍선 + 생활 흔적으로 표현.

## 직접 상호작용
가능하면 메뉴보다 공간 오브젝트 직접 터치. 밥=밥그릇, 놀이=장난감, 청소=배변, 쓰다듬기=캐릭터 직접 터치/문지르기.

## 쓰다듬기
터치 시 부드럽게 확대. 머리/배/엉덩이/등 영역. 선호 부위면 하트/긍정 피드백. 비선호 부위도 실패/강한 부정 없음.

## 첫 만남
5~10초. `{이름}가 우리 집으로 찾아왔어요.` 멜로드라마 금지. 홈으로 자연스럽게 연결.

## 꾸미기
실제 집 사진의 정체성을 유지. 생활 아이템과 소규모 장식을 추가하는 방향.

## 게임화 제한
허용: 함께한 날, 오브젝트 해금, 재화, 새로운 생활 장면.
금지: 연속 출석 압박, 미접속 손해, 펫 질병/죽음, 결제=행복 필수 조건.

## 아직 확정하지 말 것
최종 브랜드 컬러, 폰트, radius scale, shadow system, spacing token, icon style, 최종 2.5D 아트 스타일, 전체 navigation pattern, 최종 home 메뉴 위치.
