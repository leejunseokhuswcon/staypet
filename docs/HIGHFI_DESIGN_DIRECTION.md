# StayPet High-fi 디자인 방향 (v1)

작성일: 2026-09-29 · 대상: `hifi/` · 상태: 1차 시각 언어 — 검토 대기

이 문서는 **High-fi 시각 언어의 방향**을 정한다. UX 구조는 Low-fi 에서 이미 검증됐고
여기서 다시 열지 않는다. 검증된 상호작용 의미를 시각 디자인이 훼손하지 않는 것이 전제다.

---

## Product feeling

StayPet 은 **떠난 반려동물을 AI 로 재현해, 살던 집에서 스스로 생활하게 하는 디지털 반려동물 라이프 시뮬레이션**이다.

브랜드 방향은 `다시, 함께 지내는 일상.` — "다시 만나는 경험"이 아니라 **다시 함께 사는 경험**이다.

가장 강한 인상은 하나여야 한다.

> **"보리가 진짜로 우리 집에 살고 있다."**

---

## Visual thesis

**인터페이스는 방의 공기에 속한다.**

방은 화면 전체를 채우고, 절대 카드 안에 갇히지 않는다. UI 는 그 위에 붙은 레이어가 아니라
그 장면 안에 놓인 가볍고 작은 요소 몇 개다. 화면을 여는 것은 컴포넌트가 아니라 **공간**이다.

과감함은 한 곳에만 쓴다: **보리의 존재**. 접지 그림자, 방 안에서의 크기, 창에서 들어오는 빛이
그녀를 공간에 앉힌다. 그 외의 모든 것은 조용하고 절제되어 있다.

## Emotional tone

| 그렇다 | 아니다 |
|---|---|
| 따뜻하다 | 감상적이다 |
| 친밀하다 | 끈적하다 |
| 차분하다 | 가라앉아 있다 |
| 살아 있다 | 부산하다 |
| 공간적이다 | 평면적이다 |
| 현대적이다 | 차갑다 |
| 은은하게 장난스럽다 | 유치하다 |
| 믿을 만큼 정제되어 있다 | 고급스러움을 과시한다 |

핵심 규칙: **절제가 감상보다 낫다.** 슬픔을 연출하지 않는다. 추모 서비스의 시각 문법
(검은 배경, 촛불, 흐릿한 회상, 세리프 애도 문구)을 쓰지 않는다.

---

## What StayPet must never look like

- 부활/심령 서비스, 추모관 UI
- 상실 치료 앱
- 다마고치 클론, 아동용 만화 펫 게임
- 생산성 대시보드, 카드 범벅 SaaS
- 보라색 그라디언트 AI 앱
- 네온 모바일 게임
- iOS 설정 화면 복사본

**이번 회차에서 실제로 반려한 제안**: 자동 생성된 디자인 시스템이 `Claymorphism`
("toy-like, bubbly, 아동용 앱")과 `Scroll-Triggered Storytelling`(랜딩 패턴)을 1순위로 돌려줬다.
둘 다 이 제품의 금지 목록에 정면으로 들어간다. 팔레트(플레이풀 오렌지 + 트러스트 블루)와
폰트(Varela Round — 한글 미지원)도 함께 반려했다. 재검색은 `Spatial UI (VisionOS)` 를 줬는데
**깊이·레이어 개념만 취하고** 유리질 회색 실행은 버렸다(브리프가 glassmorphism 남용을 금지).

## Color direction

사진 위에서 읽혀야 하고, 예측할 수 없는 집 사진과 싸우지 않아야 한다.

### 브랜드 액센트 — Barley `#C08A3E`

`보리`는 곡식의 이름이다. 브랜드 액센트를 **보릿빛 금색**으로 잡았다.
이것은 "따뜻한 중립 + 액센트" 브리프가 거의 항상 빠지는 **테라코타/점토색을 의도적으로 피한** 선택이다.

### 보상 — Rose `#C4566B`

하트는 금색과 확실히 구분되는 **가라앉은 장밋빛**. 채도를 낮춰 축하가 아니라 애정으로 읽히게 한다.

### 중립

크림(`#F4F1EA` 류)이 아니라 **따뜻한 그레이지**. 잉크는 순수 검정이 아니라 **갈색이 도는 근사 검정 `#211C17`**.

### 차가운 균형추

`--sage-500 #6E8062` (유효한 배치, 안정), `--dusk-500 #8B90A6` (잠, 달, 저녁).
전부 따뜻한 색으로만 두면 화면이 눅눅해진다.

### 사진 위 가독성

유리질 블러에 의존하지 않는다. **불투명도 높은 잉크 스크림 알약(scrim pill)** 이 기본이고,
블러는 확대 배경과 상점 헤더 두 곳에만 쓴다.

---

## Typography

한글 가독성이 최우선이다.

**두 개의 목소리**, 각각 실제 역할이 있다.

| 서체 | 역할 |
|---|---|
| **Pretendard** (sans) | **앱이 말할 때** — 라벨, 버튼, 가격, 안내, 상점 |
| **Noto Serif KR** (serif) | **보리의 생활이 서술될 때** — 말풍선, 반응, 상태 표현 |

장식적 페어링이 아니다. 시스템의 목소리와 생명의 목소리를 구분하는 장치다.

숫자는 `font-variant-numeric: tabular-nums` — 하트 잔액과 가격이 흔들리지 않는다.

## Home composition

```
┌──────────────────────────────┐
│ ♥ 잔액            ▢ ◐ ◖ 생활 │  ← 반대편 모서리에 가벼운 요소 둘
│                              │
│         창 · 빛              │
│ ─────────────────────────────│  ← 걸레받이
│                              │
│            보리              │  ← 접지 그림자로 바닥에 앉는다
│      ▁▁▁▁                    │
│         러그 · 빛웅덩이       │
│      보리를 눌러 보세요.       │
└──────────────────────────────┘
```

우선순위: **① 보리 → ② 실제 집 → ③ 현재 행동/상태 → ④ 가벼운 조작 단서 → ⑤ 재화/상태 HUD**

- 홈 장면을 카드로 감싸지 않는다.
- 상시 버튼은 **두 개**뿐(잔액, 생활 상태). 편집은 놓은 물건이 있을 때만 나타난다.
- 방은 **명도 구조**로 만든다: 밝은 창 → 중간 벽 → 어두운 바닥 → 바닥에 떨어진 빛 웅덩이.
  모든 경계는 부드럽고, 크리스프한 벡터 도형이 없다.

## HUD strategy

`DESIGN_RULES.md` 와 `staypet_context.md` 는 **숫자형 게이지를 금지**한다.
현재 구현된 Low-fi 에는 세 상태가 있고, 이번 브리프는 그것을 High-fi 로 가져오되
훨씬 덜 대시보드처럼 만들라고 지시한다. 두 요구를 모두 만족하는 해법:

**막대 세 개를 버리고, 하나의 알약 안에 그린 글리프 세 개를 둔다. 숫자도, 라벨도, 바도 없다.**

| 상태 | 표현 | 왜 |
|---|---|---|
| 포만감 | **밥그릇이 차오른다** | 높을수록 좋다 = 채워진다 |
| 피로도 | **달이 차오른다** | 높을수록 **잠에 가까워진다** — 웰니스가 아니다 |
| 즐거움 | **공과 튀는 호가 자란다** | 높을수록 좋다 = 채워진다 |

**역방향 의미는 지표의 *종류* 자체가 전달한다.** 포만감·즐거움은 "채워짐", 피로도는 "쌓여서 잠으로 감".
같은 모양의 막대 셋이면 더 찬 쪽이 더 좋다고 읽히므로 그 방식은 쓰지 않았다.

알약을 누르면 시트가 열리고, 보리의 목소리(세리프)로 상태를 말한다 —
`기운이 넘쳐요 / 조금 나른해요 / 슬슬 졸려요 / 많이 졸려요`. 숫자는 끝까지 나오지 않는다.

HUD 는 읽히되 **보리보다 시각적으로 뒤에** 있어야 한다.

## Pet interaction

검증된 문법을 그대로 지킨다.

```
보리 탭 → 확대 → 손가락으로 직접 문지르기
```

- 첫 사용 단서: `보리를 눌러 보세요.` — **문장이 가리키는 대상 위에** 펄스 링이 붙는다.
- 확대 후: `손가락으로 보리를 천천히 쓰다듬어 주세요.` + 쓰다듬는 궤적을 그리는 점.
- 설명 문구를 늘리지 않고 **시각·모션으로** 발견성을 올린다.
- 선호 부위는 **절대 드러내지 않는다.** 신체 부위 버튼도 없다.
- 선호 부위 성공: 보리의 몸이 살짝 반응하고, 문지른 지점에서 하트가 떠오른다.
- 확대 중에는 방 HUD 가 물러나고, **잔액만 남는다** — 보상이 벌어진 자리에서 보여야 하므로.
  잔액은 이때 조작 대상이 아니며, 닫기(✕)와 같은 자리를 절대 공유하지 않는다.

## Shop

카테고리는 정확히 **가구 / 행동 / 장난감 / 옷** 네 개. 추가하지 않는다.

큰 카탈로그를 **빽빽함이 아니라 고르는 즐거움**으로 만들기 위해:

- 동일 카드 격자가 아니라 **헤어라인으로 나뉜 행**. 카드 범벅을 피한다.
- **썸네일이 물건을 따라간다** — 러그, 의자, 소파, 펫베드, 공, 로프, 뼈다귀, 모자, 코트.
  전부 같은 글리프면 94개가 한 덩어리로 보인다. 이것이 밀도 문제의 핵심 해법이다.
- 가격은 하트 글리프 + 탭룰러 숫자로 즉시 읽힌다.
- 살 수 없는 항목은 **조용히 `부족`** — 재촉도, 유도도 없다.
- 이커머스가 아니라 **우리 집의 물건 목록**처럼 보이게 한다.

## Placement

검증된 문법을 그대로 지킨다. **드래그 전용 → 미리보기 → 명시적 확인.**

- 빈 방을 탭해도 물건이 옮겨지지 않는다.
- 유효한 자리: **세이지 점선 링**. 무효한 자리: 흐려진 물건 + 중립 점선 — 경고색을 쓰지 않는다.
  (배치 실패는 잘못이 아니다.)
- 확인은 **원형 체크 52px**, 물건을 덮지 않는 자리에 놓인다.
- 배치 중에는 HUD 가 물러나고 안내 한 줄만 남는다.
- 재배치는 같은 문법을 재사용한다. 별도 "옮기기 모드 UI" 를 만들지 않는다.

## Autonomous-life representation

보리는 명령을 기다리지 않는다. **스스로 살고 있어야 한다.**

- 숨쉬기(항상), 꼬리 흔들기, 걷기, 둘러보기, 쉬기, 자기(눈 감김 + z), 놀기(튀어오름)
- 말풍선은 **줄인다.** 자세·눈·꼬리·이동이 먼저 말하고, 텍스트는 꼭 필요할 때만.
- 이동은 목적지를 향한 느린 전이 — 진동이 아니라 **건너감**으로 읽혀야 한다.

프로덕션 애니메이션을 푸는 단계가 아니다. **의도한 시각 제품을 전달**하는 것이 목적이다.

---

## Motion principles

- **연출된 순간은 하나.** 첫 하트 → 상점 전환이 그 순간이다. 섹션마다 페이드업을 뿌리지 않는다.
- 사용자의 행동에 답하는 모션은 환영한다(열림, 확정, 반응). 무작위 장식 모션은 넣지 않는다.
- 이징은 지수적 감속(`cubic-bezier(.22,.9,.28,1)`)에서 시작한다.
- 보리의 반응은 아주 짧은 오버슈트를 허용한다 — 생물의 반응이기 때문이다. UI 는 오버슈트하지 않는다.
- `prefers-reduced-motion` 을 존중한다.

---

## Accessibility

- 본문 대비 4.5:1 이상, 큰 글자 3:1 이상 — 렌더된 값으로 측정해 확인했다(실패 0).
- 모든 탭 대상 44×44 이상 — 측정해 확인했다(미달 0).
- 포커스 링은 팔레트에서 가져온다(barley). 기본 브라우저 링을 방치하지 않는다.
- 선택 영역, 스크롤바, 캐럿, 탭룰러 숫자까지 팔레트로 칠한다.
- 아이콘은 전부 **작도한 SVG** — 이모지를 아이콘으로 쓰지 않는다(0개 확인).
- 의미를 가진 아이콘에는 접근 가능한 이름을 준다.

## Visual risks

| 위험 | 내용 | 대응 |
|---|---|---|
| 방이 일러스트로 읽힘 | CSS 로 그린 방은 사진이 아니다 | 실제 사용자 사진으로 교체될 자리. 값 구조와 부드러운 경계로 사진에 가깝게 |
| 사진 위 대비 | 실제 집 사진은 밝기를 예측할 수 없다 | 스크림 알약 + 불투명도. 블러 의존 금지 |
| 달 은유 학습 | 피로도 = 차오르는 달이 즉시 읽힐지 미검증 | 시트에서 말로 확인 가능. 참가자 관찰 항목 |
| 보리의 조형 | 스타일라이즈드 플레이스홀더이지 최종 아트가 아님 | 2.5D 반실사 방향은 별도 아트 단계 |
| 따뜻함 과잉 | 금·탄·베이지가 전부 따뜻함 | sage/dusk 를 균형추로. 상점은 더 중립적으로 |
| 한글 웹폰트 | Pretendard/Noto Serif KR 은 CDN 로드 | 시스템 한글 폰트 폴백 체인 명시 |
