# StayPet High-fi 디자인 시스템 (v1)

작성일: 2026-09-29 · 구현: `hifi/styles.css` · 상태: 1차 — 검토 대기

`DESIGN_RULES.md` 는 브랜드 컬러·폰트·radius·shadow·spacing 토큰을 **"아직 확정하지 말 것"** 으로
남겨 두었다. 이 문서가 그 항목들을 **High-fi 1차 후보로** 채운다. 제품 표준 승격은 검토 후에 한다.

## 2. Typography

### 서체

```css
--f-ui:    "Pretendard Variable", Pretendard, -apple-system, BlinkMacSystemFont,
           "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif;
--f-voice: "Noto Serif KR", "Apple SD Gothic Neo", "Nanum Myeongjo", serif;
```

`--f-ui` = 앱의 목소리. `--f-voice` = **보리의 생활이 서술되는 목소리**(말풍선, 반응, 상태 표현).

### 스케일 (390px 기준)

| 역할 | 크기 / 행간 | 굵기 | 자간 |
|---|---|---|---|
| 감정 문장 (serif) | 20 / 1.5 | 400 | — |
| 화면 제목 | 17 / 1.4 | 700 | -.01em |
| 섹션 제목 | 15 / 1.45 | 600 | -.01em |
| 본문 | 16 / 1.6 | 400 | — |
| 2차 본문 | 14 / 1.55 | 400 | — |
| 캡션 | 12 / 1.4 | 400 | — |
| 버튼 | 14–15 / 1 | 600 | — |
| 가격 · 하트 잔액 | 15 | 700 | `tabular-nums` |
| HUD 라벨 | 12 | 500 | — |

본문 16px 미만을 본문에 쓰지 않는다. 위계는 **굵기와 간격**으로 먼저 만들고, 장식은 그 다음이다.

## 3. Spacing

4 / 8 리듬. `--s-1 4` `--s-2 8` `--s-3 12` `--s-4 16` `--s-5 20` `--s-6 24` `--s-8 32` `--s-10 40` `--s-12 48`

- 화면 좌우 기본 거터: **16px** (상점 행은 20px)
- 제목 위 공간 > 제목 아래 공간
- 안전 영역: `--safe-top 44px`, `--safe-bottom 34px` — 고정 요소는 반드시 이것을 존중한다

## 4. Radius

`--r-sm 8` (작은 컨트롤) · `--r-md 14` (알약, 행 썸네일) · `--r-lg 22` (시트, 카드) · `--r-full` (원형)

하나의 radius 를 모든 요소에 쓰지 않는다. 위계에 따라 다르다.

## 5. Elevation

모든 그림자는 **오프셋 + 블러**를 가진다. 제로 오프셋 컬러 헤일로는 쓰지 않는다.

| 토큰 | 용도 |
|---|---|
| `--sh-1` | 행 썸네일, 얕은 분리 |
| `--sh-2` | 시트, 방문 카드 |
| `--sh-lift` | 드래그 중인 물건, 기기 프레임 |
| `--sh-onphoto` | **사진 위 HUD 요소** (더 깊고 따뜻한 그림자) |

접지 그림자(`.pet::before`)는 예외적으로 방사형·무오프셋이다 — 그림자가 아니라 **접지면**이기 때문이다.

## 6. Motion

```css
--e-out:  cubic-bezier(.22,.9,.28,1);   /* 기본 감속 */
--e-soft: cubic-bezier(.34,.9,.42,1);   /* 호흡, 생활 */
--t-fast: 140ms;  --t-base: 240ms;  --t-slow: 420ms;
```

- 연출된 순간은 **하나**: 첫 하트 → 상점 전환.
- 보리의 반응만 짧은 오버슈트를 허용한다. UI 는 오버슈트하지 않는다.
- `prefers-reduced-motion: reduce` 에서 모든 애니메이션·전이를 사실상 0으로 만든다.

## 7. Touch rules

- 모든 탭 대상 **최소 44×44** (측정 검증: 미달 0)
- 인접 대상 사이 8px 이상
- 누름 피드백은 **레이아웃을 흔들지 않는다** — `transform: scale(.96)` + 배경 변화만
- 제스처 영역은 하나의 주 제스처만 갖는다: 방=탭, 확대 무대=문지르기, 고스트=드래그
- 드래그는 `document` 레벨에서 추적하고, 드래그 중 `touch-action: none`

## 8. Icon system

**작도한 SVG 심볼만.** 이모지·유니코드 글리프를 아이콘으로 쓰지 않는다(검증: 0개).

- 24px 그리드, 스트로크 **1.75px**, 라운드 캡/조인
- 한 위계 안에서 채움/외곽선을 섞지 않는다
- 물건 글리프는 48×32 / 32×32 그리드의 채색 심볼
- `i-heart` `i-close` `i-check` `i-back` `i-edit` / 물건: `i-cushion` `i-rug` `i-chair` `i-bed` `i-sofa` `i-ball` `i-bone` `i-rope` `i-scarf` `i-hat` `i-coat` `i-paw`

## 9. Components

### Heart balance (`.hearts`)
사진 위 스크림 알약. 44px 높이. 하트 글리프 + 탭룰러 숫자.
**상점 진입점이지만, 첫 하트 온보딩이 끝나기 전과 확대 중에는 작동하지 않는다.**
보상 시 `bump` — 잔액이 오른 것을 그 자리에서 보여준다.

### Life glyphs (`.life`)
알약 하나, 그린 글리프 셋. 숫자·라벨·막대 없음.
`포만감` 차오르는 밥그릇 · `피로도` **차오르는 달** · `즐거움` 커지는 튀는 호.
탭하면 상태 시트. 역방향 의미는 지표의 종류가 전달한다.

### Visit reward (`.visit`)
따뜻한 표면 카드, `받기` 버튼 하나. 불꽃·카운트다운·상실 경고 없음.

### First-use hint (`.hint` + `.tapdot`)
문장은 하단, **펄스 링은 대상 위**. 링의 중심 점은 항상 보이고, 확장하는 고리만 사라진다.

### Focus (`.focus`)
전체 화면. 상단 좌측 **44px 닫기**, 상단 우측 비조작 잔액 — 둘은 절대 겹치지 않는다.
확대 중 방 HUD 는 `body.focused` 로 물러난다.

### Shop item (`.item`)
헤어라인으로 나뉜 행. 썸네일(물건별 글리프) · 이름 + 설명 · 가격 · 상태 액션.
카드 격자가 아니다.

### Action states (`.act[data-state]`)

| 상태 | 라벨 | 표현 |
|---|---|---|
| `affordable` | 구매 | 잉크 채움 |
| `short` | 부족 | 비활성, 조용함, 재촉 없음 |
| `owned` | 입히기 | 외곽선 |
| `equipped` | 입는 중 | sage 채움, 비조작 |
| `active` | 사용 중 | sage 채움, 비조작 |
| `placeable` | 놓기 | **barley 채움** — 다음 행동이 있는 유일한 상태 |

### Placement (`.ghost` `.place-bar` `.confirm`)
드래그 전용 고스트 + 바닥 링(유효=sage 점선 / 무효=중립 점선, 경고색 없음).
안내 한 줄. 확인은 원형 체크 52px, 고스트를 덮지 않는 자리에 배치.

### Sheet (`.sheet`)
하단 시트, grab handle, 상태를 **보리의 목소리(serif)** 로 서술. 숫자 없음.

### Toast (`.toast`)
잉크 알약, 2.2초. 무엇이 일어났는지만 말한다.

### Object (`.obj`)
방에 놓인 물건. 편집 모드에서 이름표가 보이고 살짝 흔들린다.

## 10. Browser surfaces

기본값으로 두지 않는다.

```css
::selection { background: var(--barley-100); color: var(--n-900); }
:focus-visible { outline: 2px solid var(--barley-500); outline-offset: 2px; }
.scroll { scrollbar-width: thin; scrollbar-color: var(--n-200) transparent; }
```

숫자는 `tabular-nums`. 포커스 링은 팔레트에서 온다.

## 11. 아직 확정하지 않은 것

- 보리의 최종 2.5D 반실사 아트 스타일 (현재는 작도한 스타일라이즈드 플레이스홀더)
- 실제 사용자 사진 위에서의 스크림 강도 캘리브레이션
- 전체 navigation pattern (이번 배치는 4개 화면만)
- 다크 모드 (저녁 시간대 표현과 함께 다룰 문제)
- 로그인/등록/문답/후보 선택 화면의 시각 언어
