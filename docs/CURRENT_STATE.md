`lowfi/` 는 동결됐고 이후 변경하지 않는다.

### 7 단계에서 지금까지 된 것
High-fi 시각 언어 V1 이 `hifi/` 에 있다. 대표 4개 화면(Home · 쓰다듬기 확대 · 상점 · 오브젝트 배치)과
디자인 토큰·컴포넌트가 구현되어 있고, 390×844 에서 렌더링 검증을 마쳤다.
나머지 화면(로그인, 등록 Flow, 문답, 후보/보정, 공간 업로드, 첫 만남)은 아직 High-fi 로 만들지 않았다.

## 최근 확정된 변경사항
### 첫 진입
별도 서비스 소개 화면 없음. 앱 실행 시 강아지가 풀숲에서 뛰어노는 배경 이미지/영상 위에 StayPet 로고와 로그인 버튼 3개를 배치한다.
- `로그인하기`
- `Kakao로 시작하기`
- `Google로 시작하기`
첫 이용자는 등록 Flow, 기존 사용자는 경과시간 시뮬레이션 후 홈.

### 사진 업로드 카피
`사진 1장만으로도 시작할 수 있어요`는 표시하지 않는다. 업로드 후 `업로드 완료` 정도만 표시한다.

### 생활 습관 질문
이름과 성별을 먼저 입력한 뒤:
1. 좋아하는 쓰다듬기 부위: 머리 / 배 / 엉덩이 / 등
2. 활동량
3. 식사 주기
4. 강아지: 짖는 정도 / 고양이: 우는 정도
5. 배변 주기
6. 수면양
빈도형 UI는 왼쪽이 적음, 오른쪽이 많음/자주인 5단계 구조.

### 첫 만남
시스템 문구: `{이름}가 우리 집으로 찾아왔어요.`

### 쓰다듬기
캐릭터 터치 → 확대 → 몸의 특정 부위를 문지름 → 선호 부위와 일치하면 하트 이펙트 + 긍정 반응. 비선호 부위도 실패/부정 패널티 없음.
