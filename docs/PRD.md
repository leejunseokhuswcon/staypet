# StayPet MVP PRD v1.0

기준일: 2026-08-16
원본 기준: Notion `스테이펫 → PRD` + 최신 대화 수정사항.

## Executive Summary
StayPet은 떠나보낸 반려동물의 사진과 생활 문답으로 반실사형 2.5D 캐릭터를 만들고, 사용자가 올린 실제 공간 사진 속에서 캐릭터가 자율적으로 생활하게 하는 AI 반려동물 라이프 시뮬레이션이다. 핵심 문장: **“다시 만나는 것이 아니라, 다시 함께 지내는 일상.”**

## Problem
사진/영상은 대부분 ‘보는 기록’에 머문다. StayPet은 얼굴뿐 아니라 자던 자리, 먹고 놀던 습관, 집 안에서의 존재감을 다시 느끼게 하는 것을 목표로 한다.

검증 질문:
- 공간에서 생활하는 아이를 보는 경험이 더 가치 있는가?
- 행동/생활 패턴에서 “우리 아이 같다”고 느끼는가?
- 밥/배변/놀이가 부담보다 교감으로 느껴지는가?
- 며칠 뒤에도 다시 앱을 여는가?

## Goal & Metrics
MVP 목표: 한 번 생성하고 끝나는 AI 콘텐츠가 아니라 반복해서 돌아오는 생활형 경험인지 검증.
- Primary: 재방문
- Activation: 등록→캐릭터 생성 완료율
- Engagement: 밥/쓰다듬기/놀이/배변/꾸미기 사용
- Quality: 유사도 만족도
- Business: 유료 아이템 구매 전환
수치 목표는 비공개 베타 후 확정.

## Target User
반려동물과 이별한 경험이 있고 사진/영상을 보유하며 단순 추모보다 모습과 생활 습관을 다시 느끼고 싶은 사용자.

## Critical User Journey
1. 앱 실행
2. 로그인: `로그인하기` / `Kakao로 시작하기` / `Google로 시작하기`
3. 강아지/고양이 선택
4. 이름/성별
5. 사진 업로드 (`업로드 완료`)
6. 선택적 동영상
7. 생활 습관 문답 6개
8. AI 후보 2~3개
9. 후보 선택/간단 보정
10. 실제 공간 사진 1장
11. 이동 영역 직접 지정
12. 기본 오브젝트 배치
13. 첫 만남 5~10초
14. `{이름}가 우리 집으로 찾아왔어요.`
15. 홈
16. 자율 생활 관찰 + 직접 상호작용
17. 꾸미기/상점/앨범/추억 사진

## Core Rules
- 캐릭터는 자율 NPC.
- 오프라인은 경과시간 시뮬레이션.
- 숫자형 상태 UI 금지.
- 미접속/급식/청소 관련 해로운 패널티 금지.
- 기본 교감 경험 무료.
- 실제 사망한 반려동물 본인인 것처럼 말하지 않음.

## Out of Scope for MVP
AR, 완전 3D, 고급 실사형, 조류, 전용 SNS 공유, 의료/상담 서비스, ‘부활’ 주장.
